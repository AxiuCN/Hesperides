# 测试

## 运行

```bash
pnpm test                        # = node test/run.mjs
node test/run.mjs --list         # 只列套件
node test/run.mjs --filter=unit  # 只跑文件名含 unit 的
```

任意 cwd 可跑（套件自身用 `test/_helper.mjs` 推导路径）。全部为**离线**套件：抓取用注入的 `fetchImpl`，不联网。

## 套件

| 套件 | 覆盖 |
|---|---|
| `units.test.mjs` | 期时间解析（日/月精度、闰年 2 月）、期索引提取、期规范化（版本排序、年份纠错、end<begin、标记与原文）、ID 选择器（`keysAt`/`arrayAt`/`arrayOfArrays`/`arrayFields`）、频道表完整性（id 唯一、终局频道齐全、phased 有 period 映射、ids 有 item 模板）、schema 校验（版本不符/缺字段被拒）、内容指纹 |
| `harvest-recovery.test.mjs` | 采集恢复：TextMap 目录分隔符、失败期在索引不变时仍补抓（含「只重抓失败期、健康期不重抓」与「完整成功后的 304 仍跳过」）、更新失败保留旧文件且不前进期版本、部分 ids 失败后补抓、详情失败保留旧 detail 并可恢复、图片首命中停止与跨引用同 URL 复用 | 无（注入 HTTP） |
| `source-registry.test.mjs` | 源注册表可扩展性：注册项形状（source/channels/harvest）、频道都带 `source`、派生集合（终局/绝区零）不绑定某个源、按源分组总和等于全部频道、图片规则表可增量扩展且候选按格式偏好排序 | 无（只读模块与常量） |
| `image-prune-consistency.test.mjs` | 清理与索引/缓存一致性：清理后 `imagerefs.localPath` 与 `index.entries.icon` 都指向保留格式、元数据同步（bytes 更新、etag 清空）、连续两轮抓图零 HTTP、引用写入失败与索引写入失败后旧图仍可读且重试可完成、预览不动原字节、资源键跨源共享但按游戏/目录隔离、迁移时直接复用另一格式、首命中停止、候选失败回退 | 无（合成产物） |
| `cli-partial-failure.test.mjs` | CLI 退出码：部分条目失败时 exit 1（JSON 与非 JSON 都算）、同索引恢复后 exit 0、健康跳过 exit 0、整频道失败 exit 1 | 无（fixture + 子进程） |
| `cli-json.test.mjs` | CLI 输出契约：`--json` 时 stdout 只有可解析的 JSON（日志切到 stderr）、失败仍 exit 1、非 JSON 模式的日志与退出码不变 | 无（子进程） |
| `prune-images.test.mjs` | 孤儿图片清理：同资源多格式只留首选（webp > png > jpg）、单格式不动、占位图不参与、首选为空时不动、预览不删、执行后 `imagerefs` 的 `localPath` 改指保留文件 |
| `images.test.mjs` | 图片层：字段识别（键名/扩展名/模板占位排除）、候选 URL（原神头像→抽卡立绘、名片、星铁 sprite 目录与技能 id 回退、zzz IconMap 令牌与影画背景）、引用收集（去重、数组下标路径、空值跳过）、派生图（hsr 头像商店/抽卡/属性/命途、zzz 影画三层）、落盘路径（镜像 CDN、扩展名按 content-type、剔除 `..`）、下载（候选回退、每 URL 一次、失败候选跨轮不重探、`--retry-failed`、本地文件丢失重下）、占位图与占位口径分流（无候选 `unmapped` / 候选全失败 `unresolved`）、产物读写与 `entries` 增强（imageCount / icon）、频道级抓图（从已落盘记录收集 → 合并产物） |
| `harvest.test.mjs` | 频道抓取：首轮全抓、索引未变整频道跳过、版本变化只抓变化期、404 → `absent`、部分条目失败不算频道失败、`single` 落 `__index.json`、`static`/`text` 落盘与 hash、每频道落 manifest、导出 `index.json` + `periods.json` |
| `io-retry.test.mjs` | 重试策略对称性（打桩 `globalThis.fetch`）：文本 5xx 会重试、一直 5xx 重试到上限、网络异常重试、403/404 一次即返、文本与二进制的 502/503 行为一致 |
| `verify-integrity.test.mjs` | `--verify` 完整性边界：完好的产物通过且不误报；记录目录缺失 / 为空、图片引用指向已删文件、期表页不是数组、期表 schema 版本不符 → exit 1；台账与文件数不符、上一轮失败频道、没有台账 → 只进 notes 且 exit 0；空页（records 0）不要求记录目录；`skipped` 频道同样校验记录 | 无（合成产物 + 子进程） |

## 加套件约定

- 命名 `<主题>.test.mjs`，放 `test/`；`run.mjs` 自动发现
- 路径一律经 `_helper.mjs`（`mod()` / `rootDir` / `freshDir()`），禁止裸相对路径
- 临时产物只写 `test/.test-tmp/`（已 gitignore）
- 抓取流程用 `fetchImpl` 注入假响应，**不要在套件里访问网络**
- 断言必须能真的失败：新增套件应临时改坏被测代码确认转红，再恢复
