# 数据契约（schema v1）

## schemaVersion

- **来源**：`src/schema/index.mjs` 的常量，写入每份产物顶层；不是从数据推导
- **作用**：① 插件读前校验，不兼容直接拒绝（避免静默读出 undefined） ② 让迁移脚本可判定 ③ 产物自解释
- **何时 +1**：字段重命名 / 删除 / 语义变化 / 新增必填字段；纯新增可选字段不加
- 当前：`1`

## 产物

```
data/hesperides/
├── index.json      频道状态 + 每页记录 id（不含正文）
├── periods.json    期索引（终局类频道）
├── images.json     图片引用与落盘路径（记录级）
├── images/         图片文件（按游戏/目录镜像 CDN，按资源名去重）
├── manifest.json   增量判据（hash / lastModified / 版本 / 期列表）
└── records/
    └── <game>/<page>/<id>.json     单条记录（分片频道）
        <game>/<page>/__index.json  单文件频道（single）
        <game>/<page>/<file>.txt    text 类频道（文件名里的 / 转 __）
```

### images.json

记录级图片引用：每条引用来自记录的某个字段（`kind: field` / `iconmap`）或是派生图（`kind: derived`），
注明解析到的远程 URL 与本地文件。插件据此还原记录主图、列表缩略图，并从 `icon` 取图标。

```jsonc
{
  "schemaVersion": 1,
  "generatedAt": "2026-11-08T09:00:00.000Z",
  "games": {
    "hsr": {
      "lightcone": {
        "20000": [
          { "fieldPath": "derived.lightConeMediumIcon", "kind": "derived",
            "originalValue": "lightconemediumicon/20000",
            "remoteUrl": "https://static.nanoka.cc/assets/hsr/lightconemediumicon/20000.webp",
            "localPath": "images/hsr/lightconemediumicon/20000.webp",
            "status": "downloaded", "placeholder": false, "bytes": 64210, "etag": "" }
        ]
      }
    }
  },
  "failures": { "https://static.nanoka.cc/assets/hsr/20000.webp": { "status": "failed", "at": "…" } }
}
```

- `localPath` 相对产物根；路径镜像 CDN（`assets/<game>/<目录>/<文件>.<ext>`），扩展名以 content-type 为准
- **按资源名去重**：一个 URL 只落一个文件，多条记录共用同一张图（实测 17,209 个文件对应 10 万+ 引用）
- 候选全失败 → `localPath` 指向 `images/_placeholder/unknown.svg`、`placeholder: true`
- `failures` 记录失败候选，下一轮默认不再探测（`--retry-failed` 才重试）
- `index.json` 的 `entries[<id>]` 会补 `imageCount`（可用图数）与 `icon`（主图相对路径），插件建索引时不用读记录

### periods.json

```jsonc
{
  "schemaVersion": 1,
  "generatedAt": "…",
  "games": {
    "gi": {
      "abyss": [
        { "id": "59", "no": 59, "name": "", "version": "7.2",
          "begin": "2026-11-16", "end": "2026-12-16", "source": "alioth" }
      ]
    }
  }
}
```

- `no` 从 1 连续（按 `version` 排序后编号）
- `version` 是**上游标注的覆盖版本**，不等于"期开启日所在版本"；插件要用 `begin` 自己判版本
- 时间被修正过的期在 `manifest.phases` 里带 `timeCorrected` / `rawTime`，`periods.json` 只给已修正值

### manifest.json

```jsonc
{
  "channels": {
    "alioth:gi:abyss": {
      "status": "ok", "records": 60, "indexHash": "96f5164c-13803",
      "lastModified": "Mon, 02 Nov 2026 04:12:35 GMT",
      "phaseVersions": { "59": "7.2", "60": "7.3" },
      "phases": [ { "id": "59", "version": "7.2", "begin": "2026-11-16", "end": "2026-12-16" } ],
      "ids": [], "fileHashes": {}, "fetchedAt": "…", "error": ""
    }
  }
}
```

## 与插件 / 补丁层的对应

| 插件侧 | Hesperides 侧 |
|---|---|
| `pageKey` | `records/<game>/<page>/` 的 `<page>` |
| 条目 id | 记录文件名（`<id>.json`） |
| 期判断 | `periods.json` 的 `begin` / `end` |
| 补丁 | `resources/patch/<game>/<page>/<id>.json`（按 recordId 定位，`_patch.upstream` 存上游指纹） |
