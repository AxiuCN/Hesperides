# 数据契约（schema v2）

## schemaVersion

- **来源**：`src/schema/index.mjs` 的常量，写入每份产物顶层；不是从数据推导
- **作用**：① 插件读前校验，不兼容直接拒绝（避免静默读出 undefined） ② 让迁移脚本可判定 ③ 产物自解释
- **何时 +1**：字段重命名 / 删除 / 语义变化 / 新增必填字段；纯新增可选字段不加
- 当前：`2`

### v1 → v2 变更：源成为一等维度

v1 的产物路径只有 `<game>/<page>`，而玉璃与 nanoka 有同名页（`weapon` / `monster` / `item`），
于是**后抓的覆盖先抓的**——靠「玉璃先、nanoka 后」的顺序侥幸保证插件拿到 nanoka 形状。v2 把源写进路径：

| 产物 | v1 | v2 |
|---|---|---|
| 记录 | `records/<game>/<page>/<id>.json` | `records/<game>/<source>/<page>/<id>.json` |
| 索引页 | `games.<game>.pages.<page>` | `games.<game>.sources.<source>.pages.<page>` |
| 期表 | `games.<game>.<page>` | `games.<game>.<source>.<page>` |
| 图片引用 | 单份 `images.json` | 一页一份 `imagerefs/<game>/<source>/<page>.json` |
| 失败候选 | `images.json` 里的 `failures` | 全局 `image-failures.json` |

`source` 取值：`alioth`（玉璃）、`nanoka`。频道 id 本身已编码源（`<source>:<game>:<page>`）。

## 产物

```
data/
├── index.json        频道状态 + 每源每页的记录 id 与轻量元数据
├── periods.json      期索引（终局类频道），按 game/source/page 分组
├── manifest.json     增量判据（hash / lastModified / 版本 / 期列表）
├── image-failures.json  失败候选（下一轮默认不再探测）
├── records/
│   └── <game>/<source>/<page>/<id>.json     单条记录（分片频道）
│       <game>/<source>/<page>/__index.json  单文件频道（single）
│       <game>/<source>/<page>/<file>.txt    text 类频道（文件名里的 / 转 __）
├── imagerefs/
│   └── <game>/<source>/<page>.json          该页的记录级图片引用
└── images/
    └── <game>/<目录>/<文件>.<ext>           图片文件（镜像 CDN，按资源名去重，与源无关）
```

### index.json

```jsonc
{
  "schemaVersion": 2,
  "generatedAt": "2026-11-08T09:00:00.000Z",
  "games": {
    "gi": {
      "channels": {
        "alioth:gi:abyss": { "source": "alioth", "page": "abyss", "kind": "phased",
                             "status": "ok", "records": 60, "fetchedAt": "…", "error": "" }
      },
      "sources": {
        "alioth": { "pages": { "abyss": { "ids": [], "records": 60, "entries": {} } } },
        "nanoka": { "pages": { "character": { "ids": ["10000002"],
          "records": 154,
          "entries": { "10000002": { "name": "神里绫华", "rarity": 5, "imageCount": 12, "icon": "images/gi/UI_AvatarIcon_Ayaka.webp" } } } } }
      }
    }
  }
}
```

`entries[<id>]` 是记录级轻量元数据，让消费者**不读记录**就能建索引：
`name`、`rarity`，以及图片抓过之后的 `imageCount`（可用图数）与 `icon`（主图相对路径）。

### imagerefs/<game>/<source>/<page>.json

一页一份，插件读到哪页加载哪页（不必把十万条引用读进内存）。

```jsonc
{
  "schemaVersion": 2,
  "generatedAt": "…",
  "game": "hsr", "source": "nanoka", "page": "lightcone",
  "records": {
    "20000": [
      { "fieldPath": "derived.lightConeMediumIcon", "kind": "derived",
        "originalValue": "lightconemediumicon/20000",
        "remoteUrl": "https://static.nanoka.cc/assets/hsr/lightconemediumicon/20000.webp",
        "localPath": "images/hsr/lightconemediumicon/20000.webp",
        "status": "downloaded", "placeholder": false, "bytes": 64210, "etag": "" }
    ]
  }
}
```

- `localPath` 相对产物根，**posix 路径**；路径镜像 CDN（`assets/<game>/<目录>/<文件>.<ext>`），扩展名以 content-type 为准
- **按资源名去重**：一个 URL 只落一个文件（实测 17,209 个文件覆盖 10 万+ 引用）
- 候选全失败 → `localPath` 指向 `images/_placeholder/unknown.svg`、`placeholder: true`
- `image-failures.json`：`{ "<url>": { "status": "failed", "at": "…" } }`，下一轮默认不再探测（`--retry-failed` 才重试）

### periods.json

```jsonc
{
  "schemaVersion": 2,
  "generatedAt": "…",
  "games": {
    "gi": {
      "alioth": {
        "abyss": [ { "id": "1", "no": 1, "name": "", "version": "1.0-1.1",
                     "begin": "2020-09-15T04:00:00+08:00", "end": "…", "source": "alioth" } ]
      }
    }
  }
}
```

### manifest.json

```jsonc
{
  "channels": {
    "alioth:gi:abyss": { "source": "alioth", "game": "gi", "page": "abyss", "kind": "phased",
                         "status": "ok", "records": 60, "indexHash": "…", "lastModified": "…",
                         "ids": ["1"], "labels": { "1": { "name": "", "rarity": "" } },
                         "phases": [ { "id": "1", "begin": "…", "end": "…", "version": "1.0-1.1" } ],
                         "fetchedAt": "…", "error": "" }
  }
}
```

## 与插件 / 补丁层的对应

| 插件侧 | Hesperides 侧 |
|---|---|
| 合成路径 `hes/<game>/<source>/<page>/<id>.json` | `records/<game>/<source>/<page>/<id>.json` |
| `pageKey` | `<page>`（插件取 `nanoka` 源的页） |
| 条目 id | 记录文件名（`<id>.json`） |
| 记录主图 / 缩略图 | `imagerefs` 的 `localPath`（`images/` 前缀） |
| 期判断 | `periods.json` 的 `begin` / `end` |
| 补丁 | `resources/patch/<game>/<source>/<page>/<id>.json`（按 recordId 定位） |
